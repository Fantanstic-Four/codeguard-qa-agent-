# Retrieval Observability
OBS-001: A retrieval trace should record the query.
OBS-002: A retrieval trace should record retrieved source/chunk identifiers.
OBS-003: A retrieval trace should record similarity scores.
OBS-004: A retrieval trace should make it possible to inspect the exact text passed into model context.
OBS-005: Latency may be recorded when the model is invoked.
OBS-006: Secrets and private credentials must never be written to traces.
