# CodeGuard QA Agent — System Overview
CodeGuard helps a software engineering team turn approved feature requirements into a structured, reviewable test plan.
The primary Week 2 interaction accepts a feature name and approved Markdown/text requirements.
The output is schema-validated JSON containing status, assumptions, missing information, and no more than six proposed tests.
CodeGuard supports planning and review; it does not autonomously merge code, deploy software, or make pass/fail claims without execution evidence.
