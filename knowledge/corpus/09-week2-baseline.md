# Week 2 Baseline
The selected baseline model is Gemini 3.1 Flash-Lite.
The application uses temperature 0.2 and targets structured JSON output.
Important prompts are versioned. Week 2 contains prompt versions v1.0 and v1.1.
Prompt v1.1 strengthened exact requirement-ID citation, clarification behavior, separation of assumptions from evidence, and prohibition of invented repository/interface details.
Week 2 intentionally excluded retrieval, repository inspection, test execution, tool calling, memory, publication, and autonomous action.
