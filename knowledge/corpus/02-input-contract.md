# Input Contract
REQ-IN-001: The user shall provide a non-empty feature name.
REQ-IN-002: The user shall provide approved requirements as Markdown or plain text.
REQ-IN-003: Requirements used as evidence should contain stable requirement identifiers when available.
REQ-IN-004: Empty requirements shall not be treated as sufficient evidence for test generation.
REQ-IN-005: The application shall preserve the supplied requirement text for traceability during one request.
