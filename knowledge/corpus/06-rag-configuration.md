# RAG Configuration
CFG-RAG-001: Default chunk target is approximately 180 lexical tokens.
CFG-RAG-002: Default chunk overlap is approximately 35 lexical tokens.
CFG-RAG-003: Default retrieval top-k is 4 chunks.
CFG-RAG-004: Default minimum cosine similarity is 0.08.
CFG-RAG-005: The Week 3 reference implementation uses a TF-IDF index to keep the small controlled corpus reproducible and inspectable.
CFG-RAG-006: Supported corpus file types in the reference implementation are Markdown and plain text.
