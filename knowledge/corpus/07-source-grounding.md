# Source Grounding Rules
GROUND-001: Every retrieved chunk has a stable source identifier and chunk identifier.
GROUND-002: Source citations include the corpus file and original line range.
GROUND-003: The model receives retrieved evidence in a clearly delimited RETRIEVED EVIDENCE section.
GROUND-004: The answer should cite source/chunk identifiers for material claims.
GROUND-005: Partially supported questions must distinguish supported information from information not found in the corpus.
GROUND-006: Deliberately unanswerable questions must not be answered from general model memory as if they came from CodeGuard evidence.
