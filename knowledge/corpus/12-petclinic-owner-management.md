# PetClinic Owner Management — Approved Sample Requirements
REQ-OWN-001: A user can search for owners by last name.
REQ-OWN-002: When no owner matches a search, the system shall show that no matching owner was found.
REQ-OWN-003: A user can create an owner with first name, last name, address, city, and telephone.
REQ-OWN-004: First name and last name are required when creating an owner.
REQ-OWN-005: A user can edit an existing owner's address, city, and telephone.
REQ-OWN-006: The owner details view shall display the owner's recorded information and associated pets when available.
REQ-OWN-007: The requirements supplied for this sample do not specify authentication or authorization behavior.
REQ-OWN-008: The requirements supplied for this sample do not specify a database engine, API endpoint path, or deployment environment.
