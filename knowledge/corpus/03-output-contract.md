# Output Contract
REQ-OUT-001: The baseline response shall be valid JSON conforming to the CodeGuard response schema.
REQ-OUT-002: The response shall contain a status field.
REQ-OUT-003: The response shall separate assumptions from missing information.
REQ-OUT-004: A generated test shall cite the requirement identifier that supports it.
REQ-OUT-005: The response shall contain no more than six proposed tests in the Week 2 baseline.
REQ-OUT-006: When evidence is insufficient, the response shall request clarification instead of inventing repository or interface details.
