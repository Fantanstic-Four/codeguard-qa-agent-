The CodeGuard application source will be developed here. Week 1 defines the requirements and boundaries; the first model-backed implementation is planned for Week 2.

Planned modules include:

Web or API layer

Session and policy validation

Bounded orchestrator

Model adapter

Retrieval adapter

Approved tool gateway

Sandbox runner adapter

Trace and draft storage

The model must not receive direct operating-system, credential, or repository-write access.
