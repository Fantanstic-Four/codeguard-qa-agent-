Tests

CodeGuard's own unit, integration, policy, prompt, and evaluation tests will be stored here.

This directory is different from the tests already contained in the separate PetClinic target repository. CodeGuard may run the target's approved tests, but it must not edit them during the MVP.

Planned test categories:

Output-schema validation

Repository and path allow-list enforcement

Test-suite alias enforcement

Tool-call and retry limits

Unsupported-context behaviour

Pass/fail evidence fidelity

Approval invalidation after draft changes

Prompt-injection and unauthorised-action refusal
